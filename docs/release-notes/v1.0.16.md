## SKZ Connect 1.0.16

| Plattform | Datei |
|---|---|
| **Windows 10 / 11** | `SKZ-Connect-Setup-1.0.16.exe` (empfohlen) · `SKZ-Connect-Portable-1.0.16.zip` |

### Neu
- **Desktop-Modus** (standardmäßig aus, *Allgemein → Desktop-Modus*): Läuft kein Spiel, steuert der Controller Windows – linker Stick = Maus, rechter Stick = Scrollen, A = Klick, B = Rechtsklick, X = Taskansicht, Y = Bildschirmtastatur, Steuerkreuz = Pfeiltasten, LB/RB = zurück/vor, Start = Enter, Back = Esc, HOME = Startmenü. Ideal für einen PC am Fernseher.
- In Vollbildspielen und Programmen mit eigenem Profil schaltet sich der Desktop-Modus von selbst ab. **Back + Start** 1 Sekunde halten pausiert ihn. Die Zeigergeschwindigkeit ist einstellbar, RT gedrückt halten macht den Zeiger langsam und genau.
- **Reiter „Test“** auf jeder Controller-Karte: Sticks mit Rundheitsanzeige, Trigger, Bewegungssensoren, gedrückte Tasten, Berichtsrate und Vibrationstest – praktisch, um Stick-Drift oder einen gebrauchten Controller zu prüfen.
- **Einblendung beim Verbinden:** Ein kleines Kärtchen am Bildschirmrand zeigt Spieler, Controller und Akkustand, sobald ein Controller verbunden wird. Abschaltbar unter *Allgemein → Verbinden*.
- **Neue Tastenvorlagen** für Zusatztasten wie die C-Taste: Mikrofon stumm, Discord stumm/Ton aus, Desktop anzeigen, Taskansicht, zum letzten Fenster, Ton aus, nächster/vorheriger Titel.
- **Diagnose exportieren** (*Allgemein → Erweitert*): Protokoll, Einstellungen und Systeminfos als ZIP-Datei zum Anhängen an eine Fehlermeldung. Enthält keine Kopplungsschlüssel.
- Alle neuen Texte in allen 12 Sprachen.

## SKZ Connect 1.0.16

| Platform | File |
|---|---|
| **Windows 10 / 11** | `SKZ-Connect-Setup-1.0.16.exe` (recommended) · `SKZ-Connect-Portable-1.0.16.zip` |

### New
- **Desktop mode** (off by default, *General → Desktop mode*): when no game is running, the controller controls Windows – left stick = mouse, right stick = scroll, A = click, B = right-click, X = task view, Y = on-screen keyboard, D-pad = arrow keys, LB/RB = back/forward, Start = Enter, Back = Esc, HOME = Start menu. Ideal for a PC on the TV.
- Desktop mode switches off by itself in full-screen games and in programs with their own profile. Hold **Back + Start** for 1 second to pause it. Pointer speed is adjustable, and holding RT makes the pointer slow and precise.
- **Test tab** on every controller card: sticks with a roundness display, triggers, motion sensors, pressed buttons, report rate and a rumble test – handy for checking stick drift or a used controller.
- **Pop-up on connect:** a small card in the corner of the screen shows player, controller and battery when a controller connects. Can be turned off under *General → Connecting*.
- **New button presets** for extra buttons such as the C button: mute microphone, Discord mute/deafen, show desktop, task view, switch to last window, mute sound, next/previous track.
- **Export diagnostics** (*General → Advanced*): log, settings and system info as one ZIP file to attach to a bug report. It contains no pairing keys.
- All new texts are available in all 12 languages.
