## SKZ Connect 1.0.23

| Plattform | Datei |
|---|---|
| **Windows 10 / 11** (1.0.23) | `SKZ-Connect-Setup-1.0.23.exe` (empfohlen) · `SKZ-Connect-Portable-1.0.23.zip` |
| **Android 8+** (Beta 0.9.2) | `SKZ-Connect-Android-0.9.2.apk` |
| **Kodi / LibreELEC** (Add-on 0.4.7) | über das [DevCatSKZ Repository](https://github.com/DevCatSKZ/kodi-repo) (automatische Updates) · oder `SKZ-Connect-Kodi-LibreELEC-0.4.7-…zip` passend zum Gerät |

**Neuer Name: SKZ Connect** – auf allen Plattformen, mit neuem Icon: einer Gamepad-Katze wie bei SKZ Monitor und SKZ Remote. Unter Windows und Android übernimmt ein Update Einstellungen, Kopplungen und Autostart.

### Windows 1.0.23

#### Neu
- **Neuer Name und neues Icon** in Fenster, Infobereich, Setup und Startmenü. Datenordner und Autostart der Vorversion ziehen beim ersten Start automatisch um; Reste der alten Installation (Setup-Einträge, geplante Aufgabe) werden aufgeräumt.
- **Neun neue Farbschemata** wie in SKZ Monitor und SKZ Remote: Holo-Glas, Mitternacht, Tageslicht, Nova, Abendrot, Tiefsee, Sakura, Graphit und Samtpfoten. Holo-Glas ist der neue Standard – wer bisher kein Schema gewählt hatte, sieht es nach dem Update. Windows und die bisherigen Schemata bleiben unter *Allgemein → Darstellung und Sprache* wählbar.
- **Kodi in den Einstellungen:** zeigt, ob Kodi und das Add-on installiert sind, und erklärt, dass Kodi unter Windows kein Add-on braucht – die Controller erscheinen dort als Xbox-Controller.

#### Behoben
- Zeigte der Autostart auf eine EXE, die es nicht mehr gibt (etwa nachdem der Ordner der portablen Variante umbenannt oder verschoben wurde), startete SKZ Connect nicht mehr mit Windows. Beim nächsten Start stellt die App den Eintrag jetzt auf sich selbst um.

### Android – Beta 0.9.2

#### Neu
- Neuer Name **SKZ Connect** und neues Icon. Die Einstellungen werden beim ersten Start übernommen; die App aktualisiert sich wie bisher über *Nach Updates suchen*.

### Kodi / LibreELEC – Add-on 0.4.7

#### Neu
- Neuer Name und neues Icon. Das Add-on heißt jetzt `service.skzconnect`, das Widget-Add-on `plugin.skzconnect.status`.
- **Umstieg von der Vorversion:** Das alte Add-on bekommt keine Updates mehr. Einmal den *SKZ Connect Bundle Installer* aus dem DevCatSKZ Repository installieren oder die passende LibreELEC-ZIP – danach das alte Add-on deinstallieren. Das neue Add-on übernimmt Kopplungen und Einstellungen des alten nicht: Controller einmal neu koppeln (SYNC) und die Einstellungen prüfen.

## SKZ Connect 1.0.23

| Platform | File |
|---|---|
| **Windows 10 / 11** (1.0.23) | `SKZ-Connect-Setup-1.0.23.exe` (recommended) · `SKZ-Connect-Portable-1.0.23.zip` |
| **Android 8+** (beta 0.9.2) | `SKZ-Connect-Android-0.9.2.apk` |
| **Kodi / LibreELEC** (add-on 0.4.7) | via the [DevCatSKZ Repository](https://github.com/DevCatSKZ/kodi-repo) (automatic updates) · or `SKZ-Connect-Kodi-LibreELEC-0.4.7-…zip` for your device |

**New name: SKZ Connect** – on every platform, with a new icon: a gamepad cat like SKZ Monitor and SKZ Remote. On Windows and Android, updating keeps your settings, pairings and autostart.

### Windows 1.0.23

#### New
- **New name and icon** in the window, notification area, setup and Start menu. The data folder and autostart of the previous version move over automatically on first launch; leftovers of the old installation (setup entries, scheduled task) are cleaned up.
- **Nine new colour schemes** as in SKZ Monitor and SKZ Remote: Holo-Glas, Mitternacht, Tageslicht, Nova, Abendrot, Tiefsee, Sakura, Graphit and Samtpfoten. Holo-Glas is the new default – if you had not picked a scheme, you will see it after the update. Windows and the previous schemes remain available under *General → Appearance and language*.
- **Kodi in the settings:** shows whether Kodi and the add-on are installed and explains that Kodi on Windows needs no add-on – controllers appear there as Xbox controllers.

#### Fixed
- If autostart pointed to an EXE that no longer exists (for example after renaming or moving the folder of the portable version), SKZ Connect no longer started with Windows. On the next launch the app now points the entry to itself.

### Android – beta 0.9.2

#### New
- New name **SKZ Connect** and new icon. Settings are carried over on first launch; the app updates itself as before via *Check for updates*.

### Kodi / LibreELEC – add-on 0.4.7

#### New
- New name and icon. The add-on is now `service.skzconnect`, the widget add-on `plugin.skzconnect.status`.
- **Moving from the previous version:** the old add-on no longer receives updates. Install the *SKZ Connect Bundle Installer* from the DevCatSKZ Repository once, or the matching LibreELEC ZIP – then uninstall the old add-on. The new add-on does not take over the old one's pairings and settings: pair your controllers once more (SYNC) and check the settings.
