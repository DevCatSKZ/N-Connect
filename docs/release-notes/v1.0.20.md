## SKZ Connect 1.0.20 – now for Windows, Android and Kodi

| Platform | File |
|---|---|
| **Windows 10 / 11** | `SKZ-Connect-Setup-1.0.20.exe` (recommended) · `SKZ-Connect-Portable-1.0.20.zip` |
| **Android 8+** (beta 0.9.0) | `SKZ-Connect-Android-0.9.0.apk` |
| **Kodi / LibreELEC** | easiest via the [DevCatSKZ Repository](https://github.com/DevCatSKZ/kodi-repo) (automatic updates) · or `SKZ-Connect-Kodi-…zip` for your device |

### New
- **Android (beta):** Switch 2 controllers (Pro Controller 2, Joy-Con 2, GameCube) as a real Xbox controller for Android games, emulators and cloud gaming – no root needed via Shizuku, or root or touch controls. Remembers paired controllers, sets up the Kodi repository from the app, **12 languages**. Installation and Shizuku guide: [README › SKZ Connect for Android](https://github.com/DevCatSKZ/SKZ-Connect/blob/main/README.en.md#skz-connect-for-android-beta).
- **Windows:** new **Kodi** section in the settings – set up the DevCatSKZ Repository in Kodi with one click, download it or get the LibreELEC plugin.
- **Kodi / LibreELEC:** plugin "SKZ Connect (LibreELEC/Linux)" for all devices as ZIPs on this release and in the DevCatSKZ Repository.
