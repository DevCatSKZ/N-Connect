## N-Connect 1.0.19

| Plattform | Datei |
|---|---|
| **Windows 10 / 11** | `N-Connect-Setup-1.0.19.exe` (empfohlen) · `N-Connect-Portable-1.0.19.zip` |

### Geändert
- Der experimentelle **Export für ESP32 / nRF52840** aus 1.0.18 wurde aus dem Fenster „Kopplungsdaten“ wieder entfernt – der Ansatz wird nicht weiterverfolgt.
- Um die Controller an mehreren PCs zu nutzen, N-Connect auf jedem PC installieren und die Controller dort einmal koppeln. Kopplungsdaten an einen anderen PC weitergeben (*Allgemein → Kopplungsdaten*) funktioniert wie bisher.
- Sonst keine Änderungen für Nutzer.

## N-Connect 1.0.19

| Platform | File |
|---|---|
| **Windows 10 / 11** | `N-Connect-Setup-1.0.19.exe` (recommended) · `N-Connect-Portable-1.0.19.zip` |

### Changed
- The experimental **export for ESP32 / nRF52840** from 1.0.18 has been removed from the pairing data window – the approach is not being pursued further.
- To use your controllers on several PCs, install N-Connect on each PC and pair the controllers there once. Moving pairing data to another PC (*General → Pairing data*) works as before.
- No other changes for users.
